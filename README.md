# E-Plant Shopping

An online plant shop shopping cart application built with React and Redux Toolkit.

## Features
- Landing page with navigation to product listing
- Product cards with images, name, description, cost, and "Add to Cart" button
- Plant categories (Aromatic Plants, Medicinal Plants)
- Shopping cart with quantity controls and total calculation
- Continue Shopping and Checkout buttons

## Technologies
- React
- Redux Toolkit
- React Router DOM
- CSS

## How to Run
1. Clone the repository
2. Run `npm install`
3. Run `npm start`
